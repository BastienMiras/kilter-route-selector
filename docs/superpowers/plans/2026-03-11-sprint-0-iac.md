# Sprint 0 — Infrastructure as Code Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Set up all infrastructure as code (Containerfiles, podman-compose, Ansible, GitHub Actions) so any environment (dev-local, dev-vps, staging, prod) can be provisioned and deployed from the repository alone.

**Architecture:** Two Podman containers (FastAPI backend + Nginx frontend) orchestrated by podman-compose, deployed on a single VPS via Ansible. Three environments live on the same VPS on separate ports (dev :8082, staging :8081, prod :80). Local dev mounts source volumes for hot-reload.

**Tech Stack:** Podman, podman-compose, Ansible, GitHub Actions, GHCR, Python 3.12 / FastAPI, Nginx alpine, Ubuntu/Debian VPS.

**Spec:** `docs/plans/2026-03-11-iac-podman-design.md`

- [ ] **Step 1: Create `infra/Containerfile.backend`**

```dockerfile
# --- Builder stage ---
FROM python:3.12 AS builder
WORKDIR /app
COPY backend/requirements.txt .
RUN pip install --no-cache-dir --prefix=/install -r requirements.txt

# --- Runtime stage ---
FROM python:3.12-slim AS runtime
WORKDIR /app
COPY --from=builder /install /usr/local
COPY backend/ .
ENV PYTHONUNBUFFERED=1
EXPOSE 8000
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]
```

- [ ] Place `.env` files on VPS: `/opt/kilter-dev/.env`, `/opt/kilter-staging/.env`, `/opt/kilter-prod/.env` (use `infra/.env.example` as template)
